# Reservas de laboratorios · Departamento de Botánica, Ecología y Fisiología Vegetal (UCO)

Consulta automática de las reservas de los laboratorios del departamento en el
Sistema de Reserva de Aulas (SRA) de la Universidad de Córdoba, a partir de su
consulta pública de ocupación.

**Estado:** en pruebas. La carpeta `prueba/` comprueba si el SRA responde a
peticiones hechas desde GitHub Actions; el resultado queda en `prueba/resultado.md`.
